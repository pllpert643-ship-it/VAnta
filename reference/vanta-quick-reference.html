สถานะในตาราง

สถานะความหมาย
Queuedเข้าคิวแล้ว ยังไม่ถูกประเมินให้เริ่ม
Waitingรอ concurrency หรือ VRAM ให้พอ
RunningVAnta เปิด process แล้ว
Completedจบด้วย exit code 0
Failedเปิดไม่ได้, exit ผิดพลาด หรือไม่ผ่านกฎ VRAM
Cancelledผู้ใช้ยกเลิก

  • รู้เหตุผลของการเริ่ม, รอ หรือปฏิเสธผ่าน Decision Feed
  • ตรวจผลหลังเริ่มงานด้วย VRAM verification
